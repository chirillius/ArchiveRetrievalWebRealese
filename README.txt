Как запустить:
1. Откройте папку Release_web_1.0.0.0
2. Запустите start.bat
3. Сервис сам откроется в браузере

Важно:
- Папку нужно передавать целиком
- Для работы не требуется Node.js или другой дополнительный софт
- После запуска в окне браузера укажите адрес CentralServer
- Не закрывайте окно PowerShell, пока пользуетесь сервисом
